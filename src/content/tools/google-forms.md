# Google Forms 📝

Google Forms es una herramienta gratuita de Google que permite crear formularios, cuestionarios y encuestas de forma rápida y sencilla.

La plataforma facilita la recopilación de respuestas en tiempo real y permite al docente analizar automáticamente los resultados mediante gráficos y hojas de cálculo. Además, se puede compartir fácilmente mediante enlaces o integrarse con otras herramientas de Google Workspace.

### Como usar 
- Guía rápida: https://support.google.com/docs/topic/9055404
- Centro de ayuda: https://support.google.com/forms/
- Video introductorio: https://www.youtube.com/watch?v=KTA4PlyvyvI

### Necesidades obligatorias
- Docente tener una cuenta de Google.
- Conexión a Internet.
- Disponer de computadora, laptop, tablet o teléfono.
- Tener preparadas las preguntas o información a recopilar.
- Opcional: utilizar Google Classroom para compartir actividades.

### Recomendaciones

#### Antes de la clase
- Revisar las preguntas y configuración del formulario.
- Activar opciones de evaluación automática si es necesario.
- Probar el formulario antes de compartirlo.
- Configurar correctamente permisos y acceso.

#### Durante la clase
- Explicar cómo acceder y responder el formulario.
- Supervisar que todos los estudiantes puedan ingresar.
- Resolver dudas sobre las preguntas o envío de respuestas.
- Utilizar respuestas en tiempo real para discutir resultados.

#### Después de la clase
- Analizar gráficos y reportes generados.
- Descargar o exportar respuestas a Google Sheets.
- Brindar retroalimentación a los estudiantes.
- Reutilizar o modificar formularios para futuras actividades.

# Tables
| Problema | Posible causa |
|---|---|
| Los estudiantes no pueden acceder | Restricciones de permisos o enlace incorrecto |
| Las respuestas no se registran | Problemas de conexión a Internet |
| El formulario no permite enviar respuestas | Configuración cerrada o límite alcanzado |
| No aparecen los gráficos de resultados | Aún no hay suficientes respuestas |
| El formulario carga lentamente | Conexión deficiente o demasiados elementos multimedia |
