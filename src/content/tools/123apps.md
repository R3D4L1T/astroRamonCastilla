# 123Apps 🧰

123Apps es una plataforma en línea que ofrece múltiples herramientas gratuitas para editar audio, video, PDF y otros archivos digitales de manera rápida y sencilla.

La herramienta permite realizar tareas como cortar videos, grabar audio, convertir formatos, editar documentos y comprimir archivos sin necesidad de instalar programas adicionales. Gracias a su facilidad de uso, resulta ideal para docentes y estudiantes que necesitan crear o modificar recursos multimedia educativos.

### Como usar 
- Guía rápida: https://123apps.com/
- Centro de ayuda: https://123apps.com/help/
- Video introductorio: https://www.youtube.com/watch?v=5n9X4g0hR8M

### Necesidades obligatorias
- Conexión a Internet.
- Disponer de computadora, laptop, tablet o teléfono.
- Navegador actualizado.
- Tener preparados los archivos que se desean editar.
- Opcional: utilizar audífonos o micrófono para edición de audio.

### Recomendaciones

- Revisar las herramientas necesarias para la actividad.
- Preparar previamente los archivos multimedia.
- Verificar formatos compatibles.
- Guardar y organizar los archivos editados.
- Revisar calidad y formato de los materiales finales.
- Reutilizar herramientas futuras actividades digitales.
