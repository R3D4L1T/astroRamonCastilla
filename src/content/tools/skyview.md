# SkyView 🌌

SkyView es una aplicación educativa de astronomía que permite explorar el cielo y reconocer estrellas, constelaciones, planetas y satélites utilizando realidad aumentada.

La herramienta utiliza la cámara y sensores del dispositivo móvil para mostrar información en tiempo real sobre los objetos celestes visibles en el cielo. Gracias a su enfoque interactivo y visual, SkyView facilita el aprendizaje de astronomía de manera dinámica y motivadora.

### Como usar 
- Guía rápida: https://www.terminaleleven.com/skyview/
- Centro de ayuda: https://www.terminaleleven.com/contact/
- Video introductorio: https://www.youtube.com/watch?v=7m8KQ5f8x4A

### Necesidades obligatorias
- Disponer de teléfono o tablet con cámara y sensores.
- Instalar la aplicación SkyView.
- Conexión a Internet para algunas funciones.
- Espacio abierto para observar el cielo.
- Opcional: actividades nocturnas de observación astronómica.

### Recomendaciones

#### Antes de la clase
- Explorar previamente las funciones de la aplicación.
- Seleccionar objetos astronómicos que se trabajarán.
- Verificar funcionamiento de cámara y sensores.
- Planificar actividades según horario y condiciones climáticas.

#### Durante la clase
- Explicar cómo orientar el dispositivo hacia el cielo.
- Motivar la observación y curiosidad científica.
- Relacionar objetos observados con contenidos teóricos.
- Promover preguntas y exploración guiada.

#### Después de la clase
- Compartir observaciones y descubrimientos realizados.
- Relacionar la experiencia con temas científicos trabajados.
- Investigar más sobre estrellas, planetas o constelaciones observadas.
- Reforzar contenidos mediante actividades complementarias.

# Tables
| Problema | Posible causa |
|---|---|
| La aplicación no identifica correctamente los objetos | Sensores mal calibrados |
| El cielo no se visualiza claramente | Mala iluminación o condiciones climáticas |
| La aplicación funciona lentamente | Dispositivo con pocos recursos |
| Algunos objetos no aparecen | Configuración incorrecta de ubicación o fecha |
| Los estudiantes se desorientan al usar la app | Falta de explicación previa sobre navegación |
