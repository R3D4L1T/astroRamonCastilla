# PlantNet 🌿


PlantNet es una aplicación educativa y científica que utiliza inteligencia artificial para identificar plantas a partir de fotografías tomadas por los usuarios.

La herramienta permite reconocer especies vegetales observando hojas, flores, frutos o tallos, facilitando el aprendizaje de botánica y biodiversidad. Gracias a su enfoque interactivo y colaborativo, PlantNet ayuda a docentes y estudiantes a explorar el entorno natural y desarrollar habilidades de observación científica.

### Como usar 
- Guía rápida: https://plantnet.org/
- Centro de ayuda: https://identify.plantnet.org/
- Video introductorio: https://www.youtube.com/watch?v=0Qz6l8k8K2Q

### Necesidades obligatorias
- Disponer de teléfono o tablet con cámara.
- Instalar la aplicación PlantNet o utilizar la versión web.
- Conexión a Internet.
- Acceso a espacios naturales o plantas para observar.
- Tener interés por exploración científica y biodiversidad.

### Recomendaciones

#### Antes de la clase
- Explorar previamente las funciones de identificación.
- Seleccionar espacios o plantas adecuadas para la actividad.
- Explicar criterios básicos de observación científica.
- Verificar funcionamiento de cámara y aplicación.

#### Durante la clase
- Motivar la observación detallada de las plantas.
- Explicar cómo tomar fotografías claras de hojas o flores.
- Relacionar las especies identificadas con contenidos científicos.
- Promover preguntas e investigación sobre biodiversidad.

#### Después de la clase
- Compartir descubrimientos y especies encontradas.
- Investigar características y funciones ecológicas de las plantas.
- Crear registros o catálogos de biodiversidad observada.
- Reflexionar sobre el cuidado del medio ambiente.

# Tables
| Problema | Posible causa |
|---|---|
| La aplicación no identifica correctamente la planta | Fotografías poco claras o incompletas |
| Algunas especies no aparecen | Base de datos limitada para ciertas regiones |
| La aplicación funciona lentamente | Problemas de conexión o dispositivo limitado |
| Las imágenes no cargan | Conexión deficiente a Internet |
| Los estudiantes confunden partes de la planta | Falta de orientación sobre observación científica |
