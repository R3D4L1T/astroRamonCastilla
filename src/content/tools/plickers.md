# Plickers 📇

Plickers es una herramienta educativa que permite realizar evaluaciones y preguntas interactivas en clase utilizando tarjetas impresas que los estudiantes muestran como respuesta.

El docente escanea las respuestas con su teléfono móvil y obtiene resultados instantáneos sin que los estudiantes necesiten dispositivos electrónicos. Esto convierte a Plickers en una excelente alternativa para aulas con acceso limitado a tecnología.

### Como usar 
- Guía rápida: https://help.plickers.com/hc/en-us
- Centro de ayuda: https://help.plickers.com/
- Video introductorio: https://www.youtube.com/watch?v=Kly2Jz4Gm44

### Necesidades obligatorias
- Docente tener una cuenta en Plickers.
- Conexión a Internet.
- Disponer de un teléfono móvil para escanear respuestas.
- Imprimir las tarjetas Plickers para los estudiantes.
- Contar con proyector o pantalla para mostrar preguntas.

### Recomendaciones

#### Antes de la clase
- Imprimir y organizar las tarjetas de respuesta.
- Registrar previamente a los estudiantes en la plataforma.
- Preparar las preguntas o cuestionarios.
- Probar el escaneo antes de iniciar la actividad.

#### Durante la clase
- Explicar cómo orientar correctamente las tarjetas.
- Mostrar claramente las preguntas en pantalla.
- Escanear las respuestas lentamente para evitar errores.
- Utilizar las respuestas para generar discusión y retroalimentación.

#### Después de la clase
- Revisar los resultados obtenidos.
- Identificar estudiantes con dificultades.
- Compartir retroalimentación según el desempeño.
- Guardar las tarjetas organizadas para futuras actividades.

# Tables
| Problema | Posible causa |
|---|---|
| El docente no puede escanear las tarjetas | Mala iluminación o cámara desenfocada |
| Algunas respuestas no se registran | Tarjetas mal orientadas |
| Los estudiantes se confunden con las opciones | Explicar previamente cómo usar las tarjetas |
| La aplicación funciona lentamente | Problemas de conexión a Internet |
| No aparecen los resultados | Revisar sincronización de la cuenta |
